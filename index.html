New to Raidsmith? How it works

How it works
1

Import

Paste a Raid-Helper link or event ID, drop in the JSON, or reopen a roster you saved.

2

Optimize

Import arranges groups automatically, except that an event whose Raid-Helper groups are already set keeps them. Press Optimize after any change to rebuild your groups around the buffs that matter most. Too many sign-ups? The strongest raid gets seated and the rest wait on the bench.

3

Share

Check your buff coverage, drag anyone you want moved, then use Share: Copy for MRT for the in-game groups, or Copy live link to send the plan.
